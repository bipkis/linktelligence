Linktelligence

Экспертиза топологии ЛВС на базе обученного GNN. Передайте топологию в JSON — получите оценку качества, выявление «узких мест» и проблем безопасности.

Топология ЛВС (JSON)

Типы узлов: router, switch, printer, host, firewall, ids_ips, l3_switch. Ребро: {source, target, bandwidth, throughput}.
